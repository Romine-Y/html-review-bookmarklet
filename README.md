# Editor

在桌面 Chrome 打开 [安装页](dist/install.html)，把「Editor」拖到书签栏。打开本地 HTML，点书签，再点「开始」。安装后可离线使用。

- **编辑**：划词后点「编辑」处理选中文字。点击标签或卡片后，同一个按钮会打开区块文字编辑框。换图只在选中图片时出现。点「编辑」后直接显示适用的区块操作和格式工具。下划线、高亮和字体颜色均支持撤销。点「添加区块」可在选中区块后加入段落、标题或小标题。未选区块时添加到正文末尾。
- **批注**：选中原文或区块后添加。独立右栏可以隐藏，也可以拖动左边缘或用方向键调宽度。点「定位」跳回原文。批注随 HTML 保存。
- **工具窗**：拖动标题栏可移动。按住 Alt 点击可触发网页原有的按钮。

## 保存与退出

- **保存**：第一次在 Chrome 的文件选择器里选中并授权当前打开的原 HTML。保存会写回原文件，刷新后可见。保存成功后清空撤销历史。取消、写入失败或检测到文件变化时保留草稿。
- **另存为**：从当前草稿新建副本。当前页面、原文件和撤销历史保留。为了避免误选原文件，副本要用不同的文件名。
- **关闭或刷新**：有未保存修改时提示确认。放弃后回到最近一次保存的状态，包括正文和批注。
- **恢复**：当前标签页内可用「下载上次保存前的备份」取回最近一次覆盖前的 HTML。需要长期保留时请下载这份备份。

首次授权时请核对文件路径。书签可比较文件名，但浏览器不会把完整路径交给书签。写入时保留页面当前的脚本和样式标签，动态网页重新渲染后可能覆盖编辑。另存副本若依赖相对路径的图片或样式，放回原目录后再打开。

## 开发

用 Node.js 运行 `node build.mjs` 生成离线安装页。更新版本需要重新将安装页的按钮拖入书签栏。
